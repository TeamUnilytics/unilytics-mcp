# Changelog

2026-11-12: The npm package page no longer lists the Meta Ad Library and Moz backlink tools. Unilytics has paused both while their data providers are unavailable.

2026-11-11: The setup page for other AI apps (the npm package page) now shows the current Unilytics tools by group, and says where to get Search Console, GA4 and backlink data: from your own connectors.

2026-11-07: Claude Desktop can now connect to Unilytics by double-clicking one file and pasting your API key, with no Node or config file. See [Install the Unilytics extension for Claude Desktop](claude-desktop-extension.md).

2026-11-07: If the connection to Unilytics fails, Claude now tells you what happened and what to do, instead of losing the connection.
